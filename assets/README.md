# SynthAlign figures

Original project figures used by the SynthAlign webpage. Images are displayed at
responsive sizes; click-through links preserve their original resolution.

- `pipeline.png`: overview of the construction and training pipeline.
- `preference-examples.png`: chosen and rejected response examples.
- `image-candidates.png`: synthetic image candidates and ImageReward scores.
- `prompt-diversity.png`: prompt-class distribution by category.
- `response-lengths.png`: chosen and rejected response-length distributions.
- `qualitative-example.png`: vanilla and aligned LLaVA response comparison.
